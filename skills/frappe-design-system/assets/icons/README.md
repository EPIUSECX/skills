# Icons

This folder does not vendor Lucide or the Frappe duotone sprites.

- Sidebar rows: Lucide names, 16px, stroke 1.5. The sprite the Desk page loads is the one that draws. A name that exists only in `frappe/public/icons/lucide.svg` can be blank. See the `frappe-desk-navigation` skill.
- Dock tiles: `*-duotone` symbols from the app sprite in `app_include_icons`. 22px on the v16.52 dock (`.icon-rail`). ESS uses 24px inside the v16.50 40px tile.
- Sizes that are source-defined: 12, 16, 20, 22. Do not add 18 or 28.

The rules and the file paths are in `references/icons.md`.
