# Icons

`lucide-sprite.svg` vendors the Lucide v1.53.0 symbols the static examples use (ISC). Bodies are copied from `lucide-static`. Stroke width is set by `.icon` (1.5), not by the symbol.

- Sidebar rows: Lucide, 16px. A name that exists only in `frappe/public/icons/lucide.svg` can be blank in Desk. See the `frappe-desk-navigation` skill.
- Dock tiles: `*-duotone` symbols from the app sprite in `app_include_icons`. v16.50 draws Lucide at 20px and duotone at 24px. v16.52 draws `.icon-rail` at 22px.
- Sizes: 12, 16, 20, 24, plus 22 for the v16.52 dock only. Do not add 18 or 28.

The rules and the file paths are in `references/icons.md`.
